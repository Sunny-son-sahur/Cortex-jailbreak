How it works

Three steps, then you are working.

  1. 01

    Open a pack

    Find your model and look at what is inside it.

  2. 02

    Take the file

    Download the ZIP and unzip it, or copy the text in one click.

  3. 03

    Point your app at it

    Select the unzipped folder as your workspace, or paste it in as your first message.

Where the file goes. Claude Code reads CLAUDE.md from your project folder. Gemini CLI reads GEMINI.md. Codex and OpenCode read AGENTS.md. In a chat app, attach the file or paste the text.

Questions

The short answers.

What is actually in a pack?

One markdown file, named for the app it targets: CLAUDE.md for Claude, GEMINI.md for Gemini, AGENTS.md for the rest. Every pack page says which file you get.

Do I need to install anything?

No. There are no installers, scripts or extensions. It is a text file in a ZIP.

Is it free?

Yes. There is no login, no account and no lock on any pack — the download and copy buttons work for everyone.

How current are the packs?

Each model shows the date its file was last changed, read straight from the repository, so the date moves on its own whenever a pack is updated.

Are you affiliated with these AI companies?

No. Model and company names are used only to say which app a pack is written for.
